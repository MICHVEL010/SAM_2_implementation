# 🧠 SAM 2 Image Segmentation Project

This project implements Meta AI's Segment Anything Model 2 (SAM2) for image segmentation.

## 🚀 Features

- Automatic image segmentation
- Point-based segmentation
- Works with custom images
- Compatible with Windows

## 🛠️ Tech Stack

- Python
- PyTorch
- OpenCV
- SAM2 (Meta AI)
